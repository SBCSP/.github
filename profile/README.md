## What We Do

Most vendors cover one layer. We cover all of them — from physical installation to production-ready application delivery. We install, configure, and deploy so you can focus on running your business.

| Service | Description |
|---------|-------------|
| **Network Infrastructure** | A connected, secure network — fully installed and configured. We handle everything from low-voltage cabling to firewalls and wireless access points. |
| **Private Cloud** | Compute you own and control, without the cloud bill. We install server hardware, deploy virtualization, and configure GPU compute for AI workloads. |
| **Platform Engineering** | A self-healing application platform that deploys itself. We build container orchestration clusters, GitOps pipelines, and AI model-serving infrastructure. |

### [AI VaultIO](https://github.com/SBCSP/ai-vault)

A privacy-first macOS desktop app that combines encrypted credential storage, document indexing, and AI-powered semantic search — with a full RAG pipeline running locally.

**Key Features:**
- 🔐 **AES-256 Encryption** — Secrets, notes, and ideas encrypted at rest with PBKDF2 key derivation
- 🤖 **Dual LLM Support** — Local Ollama models or Claude API (secrets auto-locked for cloud)
- 📄 **RAG Pipeline** — Semantic search across your entire vault with cosine similarity retrieval
- 🔧 **MCP Tool Calling** — Connect to external servers (Linear, GitHub) for LLM-driven automation
- ☁️ **AWS Secrets Manager Sync** — Pull cloud secrets via SSO directly into your local vault
- 📊 **Server Monitoring** — Deploy `aiv_agent` on Linux servers for live system metrics
